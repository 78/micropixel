# Juicy Tilt 美术母图

这个目录把关卡数据和 ImageGen 美术母图分开保存。ImageGen 负责难以用程序绘制的材质、光泽和品牌感，
`generate_gameplay_assets.py` 负责精确尺寸、透明边界、tile atlas 装配和 480/720 双分辨率输出。
母图最长边统一限制为 256px：运行时机关帧最大 96px，仍保留 2.6 倍以上采样余量；标题最大 240px，
接近母图原生尺寸。这样不会把 ImageGen 的 1K–2K 中间输出原样提交到仓库。

## 母图职责

- `title-master.png`：透明背景的 `JUICY TILT` 品牌标题；
- `hud-star-filled-master.png`：透明背景的金色已收集星星；
- `hud-star-empty-master.png`：与金星同轮廓的深蓝未收集星星；
- `ice-master.png`：无河岸、无外框的青蓝裂纹冰面材质；
- `fan-master.png`：透明背景的正视科幻风扇母图；生成器固定外壳，只旋转内部叶轮并输出八帧，避免逐帧
  AI 生成造成抖动；
- `blocker-master.png`：透明背景、带青色边灯和橙色警示端灯的俯视移动挡板；
- `state-door-master.png`：透明背景的低矮状态门，定时门和压力门共享造型；
- `pressure-plate-master.png`：透明背景的低矮压力板，生成器派生熄灭和点亮状态；
- `portal-master.png`：透明背景的青色传送盘，生成器确定性派生紫色配对端；
- `levels.json`：全部碰撞和关卡几何的唯一事实来源。

`assets/launch.png` 是人工确认过的 ImageGen 启动图，不由 gameplay 素材生成器覆盖。

母图生成意图分别是：粗体倾斜的青色/银白街机标题；带切面和暖光的金色五角星；保持相同轮廓但改为
深蓝银边材质的空星；内部发光、带分叉裂纹和气泡层次的青蓝冰面。
风扇是俯视四叶涡轮、深蓝金属机身与青色发光环。材质 prompt 明确要求 full-bleed、无文字、无物体
几何和无烘焙阴影，避免 AI 图像替代碰撞数据。

运行：

```sh
python3 guest/apps/tilt/assets/source/generate_gameplay_assets.py
```

生成器会覆盖 `assets/` 中的运行时 PNG 和 `tilt_level_data.hpp`。棋盘不再按关卡烘焙整张背景，而是输出
通用底板、透明外围边框和一张 5×2 tile atlas。atlas 只包含一种无方向 2D 墙块、一块冰面和八方向
气流，共 10 帧。生成器从墙段端点和相交关系生成
`VisualWallFeature` 和 `WallJointFeature`；L02–L100 的接头中心吸附到 78px 的 7×7 迷宫网格，第一关使用精确
矩形交点。原始 `LevelData.walls` 只负责碰撞；生成器先合并共线矩形，再把显示墙段截断到每个节点的
18×18 中心方块边缘，运行时遍历 `visual_walls/wall_joints/ice/fans` 拼板。显示拓扑仍由同一份碰撞几何
确定性生成，不维护手写视觉 tile map；修改布局只需运行 `--data-only`，无需重新制作棋盘 PNG。生成器还会
逐像素确认不存在大部分区域不可见的碰撞墙。每关最多 172 个显示方块、64 个推导接头和 2 个风扇。
运行时把每段显示墙均匀拆成不超过 20×18 的近方形小块，节点本身仍是 18×18 方块。墙块使用统一底色、
窄幅四边分隔线和水平/垂直/对角线均对称的中心菱形纹理，不使用 ImageGen 金属纹理、渐变、方向光、
高光、阴影、倒角或投影；相邻块的视觉结果与绘制方向、连接顺序无关。

不要在 Bundle 的 production 构建中调用 ImageGen 或生成器。

02–100 的迷宫几何不手工维护，运行 `generate_hard_levels.py --write` 从确定性候选 seed 流重新生成；
每关默认保留 20 个通过静态约束的候选，再用生产 `TiltModel` 在三组动态相位、输入偏差和控制噪声下
逐帧试玩。只有三组都零掉落通关的候选才进入最终排序，par time 取最慢场景的 120%。脚本还会在写入
前检查通道净余量、目标可达性、机关恢复窗口和关键机关绕路代价。三颗星和终点既要保持至少四步通路
距离，也不能在画面上相邻扎堆；风扇、冰面、挡板、门和压力板都必须命中三星通关路线。紫色传送
陷阱必须位于棋盘内部的最短路线格、与其他机关隔开，截住直路，同时保留一条至少四步且经过自动驾驶
验证的完整格子旁路。
手工关还可用 `minimum_star_detour_per_mille` 声明相对直达终点路线的最低三星绕路倍率；第 4 关设为
2.2 倍并保存生产物理推荐路线，防止后续调整再次把三颗星放回顺路位置。
压力门开关不能落在自然三星路线，且额外折返要求从前期 4 步逐章增加到后期 10 步；周期风扇的最低有效推力高于最大
反向倾斜输入。生成后还必须运行生产
`TiltModel` 的 `tilt_autoplay_test.cpp`，不能把代理分数当作可通关证明。

同一张机关贴图不允许按关卡编号改变隐藏物理属性：脉冲风扇统一为 1100 推力、20 速度的入风区阵风
冲击、吹 1.4 秒、停 1.6
秒，移动机关统一为 3 秒周期，定时门统一为 3.6 秒周期且开放 1.8 秒。所有传送旁路还必须避开
风扇作用圆，并以 70px 通道开口为球保留 34px 总横向余量。

使用 `--generated-count N --output ...` 可以生成独立目录。正式目录使用十章曲线：每章第五关短暂回落，
第十关是综合考试；迷宫额外回路从前期 3 条逐章减少到后期 0 条，传送关始终保留完整安全旁路。每批候选
有固定上限，并对整个已选目录执行拓扑相似度比较。旋转或
镜像后相同的迷宫、以及完全重复的机关布局都会被淘汰。正式 `--write` 输出 L02–L100，并保留手工 L1。

技巧组合从 L8 和 L10 开始，之后每章第六关重复并逐步收窄。最终章的 L93、L96、L99、L100 启用
Inferno 约束：54px 窄口、脉冲风扇入口格与必经定时门必须位于同一条关键通路。机关物理常量保持
不变，难点来自 18px 总横向余量和停风/开门重叠窗口。
最终关自动扩大到 60 个候选，并要求生产物理中位通关时间至少 110 秒。
