# 跳一跳

支持自适应分辨率的单键跳跃游戏。按住屏幕蓄力，松手跳向下一平台；
Confirm / South 按键同样支持长按与释放。打开后直接进入游戏，第一次按下即可蓄力；
失败后点击重开，这次点击不会触发跳跃。

包含七类程序化立体平台、角色翻转与压缩动画、镜头跟随、中心连击、四类停留奖励、逐级升调蓄力音、
约三十秒的圣诞音乐盒旋律与飘动音符、独立的井盖冲水与商店门铃音效和本地最高分。
当前为独立实现的首个可玩版本，物理参数与声音尚未按特定微信版本逐帧标定。

应用大厅封面使用 `assets/launch.jpg`（720×720）；`assets/source/` 保留封面原图和生成提示词，
用于后续调整，不打入 App Bundle。

先按[构建与烧录指南](../../../docs/development/flashing.zh-CN.md)激活工具链：

```sh
python3 tools/micropixel package guest/apps/jump-jump --aot-target riscv32-ilp32f --profile release

# 先通过 MAC 确认 S31，再设置 DEVICE_PORT，并关闭其他串口工具。
python3 tools/micropixel --transport usb --port "$DEVICE_PORT" \
    run guest/apps/jump-jump --profile release --no-follow
```

普通落地得 1 分，连续中心得 2、4、6……分，单次最多 32 分；回落原平台不得分。
井盖、魔方、商店、唱片平台静置两秒分别奖励 5、10、15、30 分，每个平台只能领取一次。
蓄力时不触发停留奖励；系统恢复或输入取消会清除未完成的蓄力，不会自动起跳。

支持宽高均不小于 240 像素的屏幕，包括 320×240、480×480、720×720 及竖屏。
场景按短边等比缩放、居中显示，背景铺满屏幕；文字使用设备原生字号，小屏提示采用短文案。
整屏均可触摸操作，包括方形游戏区域以外的空白处。分辨率不改变蓄力、跳跃和碰撞判定。
启动时仍检查多边形绘制能力。只构建独立 App Bundle，
无需重建 Host 或出厂 App Store。原生分辨率下，每个缓冲区首次清屏，之后分别记录上次内容覆盖的 32 段水平区域；
复用时通过 Host 矩形填充只清除旧内容，再绘制当前画面，减少空白背景的重复写入。
任一边长超过 480 的屏幕默认三缓冲，其他屏幕双缓冲；第三个缓冲区分配失败时回退到双缓冲。
720×720 下第三个 RGB565 缓冲区额外占约 0.99 MiB。`--buffers=2` / `--buffers=3` 可用于对照测试，
运行参数 `--perf` 输出分阶段耗时、帧率和实际缓冲区数量。
架构、玩法规则和测试命令见 [README](README.md)，音频约定见[音频说明](audio/README.md)。

特殊造型通常每 5 次成功跳跃出现一次，超过 1,000 分后间隔增至 6 次；其中只有 4/17 的
候选类型提供停留奖励。薄圆桌面、中央支柱的小圆桌属于普通平台池，开局阶段也能出现；
普通平台随得分事件逐步缩小，后期的小圆桌落脚面积明显收窄。未制作的特殊造型暂用普通平台表现，不额外加分。
这采用了 2017 年历史存档的间隔规律，尚未完整复刻原版 30 种模型与对象池抽取。
停留奖励从落地起计两秒。蓄力取消或松手仅停止后续音符，已发出的声音在最多 110 毫秒内自然衰减。
